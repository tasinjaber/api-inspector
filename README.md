# API Inspector

A developer-focused REST API workspace built with React and TypeScript.

## Features

- REST method and URL editing
- Saved request collection
- JSON request-body editor
- Response status and formatted payload viewer
- Copy response action
- Responsive developer-tool layout
- Typed request models
- Vitest, ESLint and GitHub Actions CI

## Run

npm install
npm run dev
npm run check

## Stack

React · TypeScript · Vite · Vitest · ESLint · GitHub Actions
